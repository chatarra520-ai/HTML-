:has es un selector que no perdona

:has significa "que tenga dentro". Es un selector de CSS que elige un elemento según lo que contiene. 

.tarjeta:has(img) {
    border: 2px solid tomato;
}

Se lee así: "elige las .tarjeta que tengan un img dentro". Solo la primera recibe el borde.

Ventajas
Reemplaza JavaScript en muchos casos. Antes, "estilar un contenedor según lo que tiene dentro" exigía código JS que detectara el contenido y añadiera una clase. Ahora es una línea de CSS.
