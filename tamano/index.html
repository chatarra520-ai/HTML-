El ancho estándar de un sitio web en 2026 es de 1366–1440 px en escritorio, con el contenido principal dentro de un contenedor de ~1140–1200 px. Las resoluciones de pantalla más comunes son 1920×1080 (escritorio), 768×1024 (tableta) y 360×800 (móvil); diseña de forma responsiva para que un único diseño se adapte a las tres.

Los requisitos de diseño web cambian a medida que las personas interactúan con los sitios en distintos dispositivos, desde pantallas grandes hasta móviles. Elegir los tamaños de sitio adecuados permite presentar el contenido con calidad, ofrecer una navegación sencilla y lograr una carga rápida.
